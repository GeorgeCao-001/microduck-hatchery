# Microduck Hatchery Web 视觉规范

本文件保留设计包的视觉基线、素材来源与脚本参考。当前页面和验证状态以 [LOCAL_STATUS.md](LOCAL_STATUS.md) 为准；联调当前布局与使用见 [JOINT_COORDINATION.md](JOINT_COORDINATION.md)，七章与正式设备契约仍参照 [审查稿](LOCAL_REVIEW_PROPOSAL.md)。尚未授权的布局调整仍须审查。

## 视觉方向

纸白底色、深绿黑正文与代码区域、少量芥末黄强调，使用真实照片和技术文档排版。介绍页采用大幅实物照片与不对称编排；展示页围绕真实视频与实验条件；教程采用适合长文阅读的版式；调试台采用清晰的关节调节大面板与大曲线，单关节保留表格与详情。避免所有页面重复使用后台卡片布局。

语义 token 见 [tokens.json](../tokens.json)。英文用 Manrope，代码和数值用 IBM Plex Mono；Figma 中文用 Noto Sans SC，原型中文使用 Noto Sans SC / PingFang SC / Microsoft YaHei 系统回退，未打包完整中文字体。

设计基线字号：桌面介绍页主标题 64/84、正文 16/28、文章 18/32，手机标题 36/50；间距使用 4、8、12、16、24、32、48、64、80、96。按钮有默认、悬停、焦点和禁用状态。保留可见键盘焦点、跳到正文、文字状态、图表说明与减少动态效果支持。

## 页面与交互约束

- 全部 15 个物理关节始终存在，包括嘴部。显示左腿 → 右腿 → 头颈嘴；缺测显示“—”，不能补零或隐藏关节。
- 联调在一个大面板中完整展示三组各五张关节卡片，不设内部列表滚动，保留目标滑块、数字输入和小步增减。桌面调节与大曲线并排，窄屏上下堆叠，通过页面滚动查看。
- 单关节调试保留独立滚动列表；选择关节只局部更新详情，保留列表位置和编辑焦点。桌面导航保持 150 px 宽度与正常字号，可收起，不通过缩小文字挤出图表空间。
- 联调保留草稿编辑、范围选择与逐项检查；更多草稿操作和姿态区域可展开。反馈不覆盖草稿，加载姿态不执行；校准未知时镜像禁用。
- 曲线设置以 14 px 正常字号展示，默认收起，摘要显示已选关节与数据项数。图表关节选择独立于草稿应用范围，位置/目标回读及实测减目标误差以 ticks 显示，raw load、电压 V、温度 °C 分图，raw load 不标成扭矩。
- 教程导航和当前章小节在同一栏，黄色指示跟随上下阅读。目标结构为七章，现有原型仍是六章。
- 样例、未连接、陈旧、只读和未知状态都用文字说明；实机按钮当前禁用，ticks 与未校准角度不混用。
- 暂停显示、停止记录、停止序列和关闭使能分别表达；release 不称为急停。联调暂停只冻结绘图，样例采集继续；切换单关节或离开调试台停止联调样例计时。
- 连续曲线当前仅有左膝的浏览器生成样例，电压与温度为恒定样例；其余关节和 raw load 保持缺测。目标草稿不替代目标回读；10/30 秒图表使用浏览器单调相对时间，不标成设备 Unix 时间。缺测与过长采样间隔断段，有界历史不宣称真实遥测已接通。
- 生成曲线、CSV 和参考照片明确标记来源；正式记录回放只读。
- Web 不包含 3D、浏览器仿真或策略推理，RL、标准导出和 FT 运行时属于整机与七章主线。

[拆分原型](../prototype/index.html) 与 [单文件原型](../Microduck-Hatchery-Visual-Prototype.html) 使用已有照片和字体，无 CDN 依赖。团队正式照片、视频与实测内容仍需逐步补齐。
