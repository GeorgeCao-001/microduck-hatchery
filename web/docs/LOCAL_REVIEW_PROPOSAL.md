## 2. 调试台布局

保留“单关节调试”，联调为默认入口。按用户最新要求，联调不设内部列表滚动，15 个关节在一个大面板内完整展开，保留目标滑块、数字输入和小步增减；桌面调节与大曲线并排，窄屏上下堆叠。范围、草稿、反馈、姿态与连续曲线均为本地样例。

| 区域 | 建议内容与行为 |
|---|---|
| 顶部 | 身份、样例/实机来源、会话、连接、数据年龄、模式与控制权 |
| 面板工具栏 | 全部/左腿/右腿/头颈/自定义范围；显式“应用已选关节”；反馈填充及保存/加载姿态在可展开的更多草稿操作中 |
| 联调大面板 | 左腿、右腿、头颈与嘴部三组各五张卡片；15 个关节始终存在；没有内部列表滚动；范围选择不会隐藏未选关节 |
| 每张关节卡片 | 选择框、名称/ID、目标滑块与数字输入/小步增减、反馈与年龄、文字状态、最近样例结果 |
| 大曲线面板 | 独立选择关节与数据，位置、误差、raw load、电压、温度分图；设置默认收起并显示“X 关节 · Y 数据”摘要，展开控件保持 14 px 正常字号 |
| 导航与单关节 | 桌面导航保持 150 px 宽度与正常字号，可收起；单关节列表继续独立滚动，详情保留 |
| 两视图切换 | 保留选择、草稿与单关节列表滚动状态；切换关节不重建调节面板、不丢焦点；离开联调停止样例计时 |

曲线显示范围与草稿应用范围互相独立。当前仅左膝 #23 每 200 ms 生成连续位置/目标样例，误差为实测回读减目标回读；电压 7.8 V、温度 32 °C 是恒定样例。其他关节和 raw load 保留缺测，raw load 不换算或标成扭矩。目标草稿不能替代目标回读，也不能用于声称物理误差。

显示支持 10/30 秒窗口，使用浏览器单调相对时间，每关节最多保留 320 点；null 与超过 0.65 秒的采样间隔使曲线断段。暂停只冻结绘图，样例采集继续，切换到单关节或离开调试台停止计时。当前没有真实 gateway 数据或设备 Unix 采样时间；正式时钟与失联契约仍在协议阶段核对。

保留纸白 `#F5F3EE`、深绿黑文字、芥末黄 `#F2B544`、真实照片和技术文档方向。黄色用于选择和阅读位置；离线、未知、待应用、失败同时有文字，不能只依赖颜色。硬件能力未具备时动作仍禁用，样例结果明确标注。

## 4. 草稿、反馈与批量结果

建议独立保存三类数据：目标草稿、带来源/有效期的设备反馈、最近命令结果。草稿以关节 ID 索引，记录编辑版本；收到反馈只更新反馈层，切换视图与加载新状态不会覆盖用户输入。

流程为：编辑多个目标 → 检查范围、单位、限位和控制权 → 显式应用 → 显示总体与逐关节结果。发送时快照化本次草稿，后续继续编辑不会改变在途命令。未选关节不发送；部分失败不得被总体“成功”掩盖。接收、写入/应用、反馈确认与到达目标是不同阶段，必须按实际可证实能力命名，不能凭点击生成成功。

未得到有效校准时显示 ticks。草稿可以设计，但可执行滑块范围必须来自验证过的设备/映射/校准信息；不沿用现有左膝样例的 112–136。角度转换需要零位、方向、比例及限位；缺失时不标成准确度数、不自动裁剪后执行。

左右联动在已验证的语义角度或相对姿态中做镜像，再经各侧方向、零位和比例转换回 ticks。镜像符号与基准需逐对核对，不能凭名称猜符号，也不能直接复制原始 ticks；校准不足时镜像不可用。

“当前位置填充”只使用有效反馈，并明确影响范围及跳过结果。“保存姿态”记录映射、校准、单位和目标。“加载姿态”检查版本与范围，只改草稿，绝不自动发送；不兼容项目逐项提示。断线/重连不执行旧草稿、不重放命令、不自动使能。

现阶段不设计连续发送默认行为。批量写入不保证物理时间上的绝对同步，后续依设备能力明确时序。
