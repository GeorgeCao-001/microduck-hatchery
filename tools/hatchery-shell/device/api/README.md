# 样例工具的 API 传输入口

`app.py` 为本地只读样例工具提供 HTTP/WS 传输，并且只挂载仓库根目录下 `web/prototype/` 和 `web/shell/` 静态目录。仓库根目录、设备代码、日志和协议夹具不作为静态目录公开；此工具不承担板端 gateway 或 robotd 的职责。

- `GET /api/v1/info`：后端会话、能力、样例标志与全部 15 个关节元数据。
- `GET /api/v1/state`：带来源、单位明确字段、帧序号与时间的样例状态。
- `WS /api/v1/ws`：连接后发送 `hello` 和首个 `state`，每 0.5 秒发送新样例帧；客户端无需发送订阅命令。
- 所有 API 非 GET/HEAD 请求由控制器拒绝并返回 HTTP 403；所有 WS 客户端消息返回 `read_only` 错误，没有成功回执。
- 未知 HTTP API 返回 JSON 404；不会回退到前端页面。

路由不持有总线、运行控制循环或授予控制权。WS 断开取消该连接的发送与接收任务；重连只读取当前会话，不能补发目标。
